Deskripsi Event :
Tim SOC mendeteksi adanya percobaan komunikasi anomali yang terjadi pada:

Source IP :
{src_ip}

Source IP Country :
{src_country}

Destination IP :
{dst_ip}

Destination Port :
{dst_port}

===============================

Event ini terdeteksi karena IP source {src_ip} teridentifikasi oleh rule Suricata sebagai IP yang termasuk dalam daftar known compromised atau hostile host dengan signature "ET COMPROMISED Known Compromised or Hostile Host Traffic group", yang mengidentifikasi traffic dari IP yang diketahui atau terindikasi sebagai compromised/hostile host.

Berdasarkan log, terdapat koneksi TCP dari IP public {src_ip} menuju aset internal {dst_ip}  pada port {dst_port} . Traffic terdeteksi oleh Suricata dengan action "Allowed". Aktivitas ini perlu dilakukan validasi untuk memastikan apakah koneksi tersebut memiliki kebutuhan bisnis yang legitimate.


===============================

Mitigasi :

- Periksa apakah IP Source {src_ip} memiliki kebutuhan komunikasi yang legitimate atau telah terdaftar sebagai IP yang diperbolehkan.
- Lakukan pengecekan pada log web server/application/service di host {dst_ip}  untuk memastikan tidak terdapat aktivitas mencurigakan atau aktivitas lanjutan dari source IP tersebut.
- Apabila tidak terdapat kebutuhan komunikasi yang legitimate, lakukan blocking terhadap IP Source {src_ip} pada perimeter firewall.
- Lakukan monitoring terhadap host tujuan {dst_ip}  untuk memastikan tidak terdapat indikasi kompromi atau aktivitas mencurigakan lainnya.
