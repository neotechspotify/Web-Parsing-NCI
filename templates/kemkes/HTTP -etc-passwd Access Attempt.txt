===============================

Berdasarkan log yang tersedia, Palo Alto mendeteksi adanya percobaan akses terhadap file sistem /etc/passwd pada layanan web yang berjalan di destination melalui port 80. Aktivitas tersebut terdeteksi dengan signature HTTP /etc/passwd Access Attempt (35107) dan dikategorikan sebagai info-leak, yang mengindikasikan adanya potensi percobaan Information Disclosure melalui aplikasi web.
Traffic tercatat dengan action ALLOW, sehingga komunikasi tersebut diizinkan oleh firewall. Namun, berdasarkan log ini belum dapat dipastikan apakah request tersebut berhasil membaca file `/etc/passwd` atau hanya merupakan percobaan akses yang ditolak oleh aplikasi

===============================

Mitigasi :<br>
- Verifikasi apakah komunikasi dari alamat IP sumber  merupakan aktivitas yang sah atau memiliki kebutuhan bisnis yang valid
- Lakukan pemeriksaan pada access log dan application log host untuk memastikan apakah terdapat request terhadap /etc/passwd dan apakah request tersebut berhasil mendapatkan response
- Periksa status HTTP response dari request tersebut, khususnya apabila ditemukan response 200, untuk memastikan tidak terjadi pengungkapan informasi sistem
- Lakukan pemeriksaan terhadap aplikasi/service yang berjalan pada port 80 dan pastikan tidak terdapat vulnerability seperti Path Traversal atau Local File Inclusion (LFI) yang dapat digunakan untuk mengakses file sistem
- Lakukan update atau patch terhadap aplikasi, framework, maupun service yang berjalan pada host tujuan apabila ditemukan versi yang rentan
- Pastikan aplikasi web berjalan dengan prinsip least privilege dan tidak memiliki hak akses berlebihan terhadap file sistem
- Lakukan monitoring terhadap host tujuan untuk memastikan tidak terdapat percobaan eksploitasi, enumeration, maupun aktivitas mencurigakan lainnya dari alamat IP sumber tersebut
