Firewall Palo Alto mendeteksi trafik dengan signature Non-RFC Compliant HTTP Traffic on Port 80, yang menunjukkan adanya paket atau permintaan HTTP pada port 80 yang tidak mengikuti format standar protokol HTTP sesuai RFC.

Aktivitas seperti ini dapat disebabkan oleh:

- Upaya reconnaissance atau pemindaian terhadap layanan HTTP.
- Penggunaan tool eksploitasi atau vulnerability scanner yang mengirimkan request HTTP tidak valid.
- Malware atau bot yang menggunakan format HTTP yang dimodifikasi.
- Aplikasi atau perangkat yang mengirimkan trafik HTTP non-standar.

Pada log ini, trafik diizinkan (Allowed) sehingga disarankan untuk melakukan verifikasi lebih lanjut terhadap log web server guna memastikan tidak terdapat aktivitas eksploitasi lanjutan maupun respons yang menunjukkan keberhasilan akses.

===============================

Mitigasi :<br>
- Lakukan pemeriksaan log web server pada {dst_ip} untuk mengetahui request HTTP yang diterima dan respons yang diberikan.
- Verifikasi apakah request tersebut merupakan aktivitas yang sah atau berasal dari vulnerability scanner maupun bot otomatis.
- Pastikan web server dan aplikasi telah diperbarui dengan patch keamanan terbaru.
- Terapkan atau optimalkan Web Application Firewall (WAF) untuk memblokir request HTTP yang tidak sesuai standar maupun pola eksploitasi yang dikenal.
- Monitor aktivitas lanjutan dari {src_ip}. Apabila teridentifikasi sebagai aktivitas scanning atau eksploitasi yang berulang tanpa kebutuhan bisnis, pertimbangkan pemblokiran sesuai kebijakan keamanan.
