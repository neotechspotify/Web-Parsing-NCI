Deskripsi Event :
Tim SOC mendeteksi adanya aktivitas pemindaian (probe) ke server internal yang mencoba mengakses fitur Laravel Debug Mode (.env / debug info) secara otomatis dari luar. Akses ini berpotensi membuka informasi sensitif seperti kredensial, kunci API, atau konfigurasi aplikasi jika fitur debug mode aktif di lingkungan produksi.

Suricata mendeteksi permintaan HTTP POST yang sesuai dengan signature ET SCAN Laravel Debug Mode Information Disclosure Probe Inbound. Payload request berisi parameter:

0x%5B%5D=androxgh0st

Parameter tersebut merupakan indikator yang sering dikaitkan dengan aktivitas AndroxGh0st, yaitu malware dan toolkit yang digunakan untuk melakukan pemindaian terhadap aplikasi Laravel yang masih mengaktifkan APP_DEBUG=true. Apabila mode debug masih aktif, penyerang dapat memperoleh informasi sensitif seperti konfigurasi aplikasi, kredensial, environment variable, maupun detail sistem yang dapat dimanfaatkan untuk serangan lanjutan.

Berdasarkan log yang diterima, aktivitas terdeteksi sebagai Allowed, sehingga diperlukan verifikasi pada server tujuan untuk memastikan aplikasi tidak berjalan dalam mode debug dan tidak terdapat informasi sensitif yang terekspos.

===============================

Mitigasi :
- Verifikasi konfigurasi aplikasi Laravel dan pastikan APP_DEBUG=false pada lingkungan produksi.
- Pastikan file .env tidak dapat diakses dari internet dan tidak mengekspos informasi sensitif.
- Review web server log dan application log untuk mengidentifikasi request serupa maupun aktivitas lanjutan dari alamat IP sumber.
- Perbarui framework Laravel beserta seluruh dependency ke versi yang telah mendapatkan patch keamanan.
- Terapkan Web Application Firewall (WAF) untuk memblokir pola eksploitasi yang mengarah pada Laravel Debug Mode.
- Apabila aktivitas berasal dari sumber yang tidak memiliki kebutuhan bisnis yang sah dan terjadi secara berulang, pertimbangkan pemblokiran terhadap alamat IP sumber sesuai kebijakan keamanan.
