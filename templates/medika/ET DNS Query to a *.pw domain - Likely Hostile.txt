Alert ini mengindikasikan adanya query DNS ke domain dengan TLD .pw yang dikenal sering digunakan dalam aktivitas berbahaya seperti phishing, malware hosting, atau command and control (C2). Meskipun tidak secara langsung membuktikan adanya serangan, aktivitas ini termasuk kategori potentially hostile dan memerlukan investigasi lebih lanjut untuk memastikan legitimasi domain yang diakses.

===============================

Mitigasi :
- Lakukan pemeriksaan pada host internal yang melakukan query DNS untuk mengidentifikasi proses atau aplikasi penanggung jawab.
- Jalankan pemindaian antivirus/EDR pada host internal untuk memastikan tidak ada malware aktif.
- Blokir domain atau kueri DNS ke domain *.pw berreputasi buruk pada DNS Resolver / Secure Web Gateway / EDL.
- Monitor lalu lintas jaringan keluar dari host terkait untuk menganticipasi potensi komunikasi C2 lanjutan.
