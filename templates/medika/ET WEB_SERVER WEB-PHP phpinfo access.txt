Terdeteksi percobaan akses ke endpoint /phpinfo.php pada web server melalui metode HTTP GET. File phpinfo.php merupakan halaman diagnostik PHP yang dapat menampilkan informasi konfigurasi server, seperti versi PHP, modul yang aktif, path aplikasi, dan konfigurasi sistem. Aktivitas ini umumnya merupakan bagian dari reconnaissance untuk mengidentifikasi informasi yang dapat dimanfaatkan pada tahap eksploitasi berikutnya.

===============================

Mitigasi :
- Verifikasi apakah file phpinfo.php masih tersedia dan dapat diakses dari jaringan publik.
- Hapus atau nonaktifkan file phpinfo.php pada lingkungan produksi apabila tidak diperlukan.
- Batasi akses ke halaman diagnostik hanya untuk administrator atau jaringan internal.
- Tinjau log web server untuk memastikan respons terhadap permintaan tersebut dan mendeteksi adanya aktivitas lanjutan dari alamat IP sumber.
- Terapkan aturan pada WAF atau IDS/IPS untuk memblokir atau memonitor akses ke file diagnostik dan endpoint sensitif guna mencegah upaya reconnaissance lebih lanjut.
===============================
