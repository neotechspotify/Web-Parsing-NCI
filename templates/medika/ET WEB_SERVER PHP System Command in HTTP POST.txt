Alert menunjukkan adanya file PHP yang disamarkan sebagai file gambar (image/gif) menggunakan teknik *GIF/PHP Polyglot. Payload yang terdeteksi mengandung fungsi system() yang dapat digunakan untuk menjalankan perintah pada sistem operasi apabila file berhasil diunggah dan dieksekusi. Aktivitas ini merupakan indikasi **percobaan Remote Code Execution (RCE)* melalui mekanisme upload file.

===============================

Mitigasi :

- Verifikasi apakah file *img_7a16eaea.php* berhasil tersimpan pada server, kemudian segera hapus apabila ditemukan.
- Periksa access log dan error log web server untuk memastikan tidak terdapat akses lanjutan terhadap file yang diunggah.
- Nonaktifkan eksekusi file PHP pada direktori upload.
- Terapkan validasi upload berdasarkan ekstensi, MIME type, dan magic bytes (allowlist file).
- Lakukan pemindaian terhadap server untuk memastikan tidak terdapat web shell atau backdoor lainnya.
