Event ini terjadi karena IP Source tersebut terdeteksi dalam database/intelijen Threat Intelligence memiliki reputasi buruk dan pernah dilaporkan terlibat dalam berbagai aktivitas berbahaya, termasuk RDP brute force, port scanning, dan network reconnaissance. Aktivitas ini mengindikasikan adanya upaya pemindaian atau percobaan akses terhadap layanan RDP yang berjalan pada port non-standar (kustom) ke aset internal

===============================

Mitigasi :
- Verifikasi apakah port non-standar tersebut sengaja digunakan untuk layanan RDP sah.
- Batasi akses ke port RDP/Terminal Server hanya melalui jaringan terproteksi seperti VPN dengan autentikasi multi-faktor (MFA).
- Terapkan Network Level Authentication (NLA) dan enkripsi kuat pada konfigurasi RDP.
- Blokir IP sumber pada firewall atau EDL jika terdeteksi melakukan scanning secara massif.
- Periksa apakah IP Source memiliki keperluan bisnis yang valid atau terdaftar pada whitelist internal.
- Periksa apakah server tujuan memang menggunakan Remote Desktop Gateway (RD Gateway) atau layanan RDP melalui port kustom sebagai bagian dari konfigurasi yang valid.
