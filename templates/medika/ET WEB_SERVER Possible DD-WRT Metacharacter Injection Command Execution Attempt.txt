Deskripsi Event :
Tim SOC mendeteksi adanya percobaan injeksi karakter metakarakter (Metacharacter Injection) dalam permintaan HTTP menuju server internal. Pola ini mengindikasikan upaya eksploitasi eksekusi perintah (Command Execution / Command Injection) pada komponen web server.

===============================

Berdasarkan hasil analisis, request HTTP tersebut mengandung karakter metacharacter (;) yang digunakan untuk menyisipkan beberapa perintah shell secara berurutan. Payload mencoba berpindah ke direktori /var/tmp, menghapus isi direktori, mengunduh file Mozi.m dari server penyerang menggunakan wget, kemudian mengeksekusi file tersebut menggunakan sh. Pola ini mengindikasikan upaya eksploitasi OS Command Injection untuk mengunduh dan menjalankan malware pada sistem target.

===============================

Mitigasi :
- Periksa log aplikasi web dan web server pada port sasaran untuk memvalidasi permintaan dan respon server.
- Terapkan validasi dan sanitasi input yang ketat pada seluruh parameter HTTP yang diterima aplikasi.
- Konfigurasikan Web Application Firewall (WAF) untuk memblokir karakter khusus dan peranti perintah sistem dalam URL maupun body request.
- Blokir alamat IP sumber pada firewall atau EDL.
